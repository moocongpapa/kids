# 놀이 그림·표정 업그레이드 · 2026-10-07

## 반영 범위

5개 투명 이미지 시트의 **48개 그림 셀**을 앱에 추가했다. 캐릭터 표정·동작 20개, 놀이 소품 24개, 숲 바닥 4개다. 기존 Flame 장면과 Flutter 장난감이 같은 그림을 사용한다.

- 먹이주기: 모모가 열매를 바라보고 입을 벌린 뒤 씹고 만족하는 표정으로 바뀐다. 열매가 몸 중앙이 아닌 부리로 이동한다. 중복 터치는 한 번만 처리한다.
- 감각 장난감 5종: 열매·바구니·숨는 덤불·캐릭터에 같은 수채화 질감을 적용했다. 실로폰은 나뭇결과 조명을 더했고 큰 연주 영역을 유지했다.
- 월령 놀이: 다리의 판자, 집의 지붕·벽, 버스와 승객, 피어나는 꽃, 소풍과 연주 무대에 전용 그림을 사용한다. 선택한 재료와 조립 결과는 기존 놀이 규칙에 따라 동작한다.
- 기존 놀이와 홈: 공통 캐릭터·소품·배경을 통해 새 그림을 공유한다. 동작 따라 하기는 두리의 팔 벌리기·올리기·걷기·쉼 자세를 사용한다. 그리기와 색칠의 자유로운 선·도형 기능은 유지한다.
- 공간감: 풀밭·시냇가·소풍 자리·통나무 무대를 공통 바닥으로 사용하고 캐릭터와 열매에 접지 그림자를 더했다. 배경은 손가락 이동에 최대 3픽셀만 반응한다.

캐릭터 동작은 그림 프레임 전환이다. 뼈대 애니메이션이나 3D 모델을 도입한 것은 아니다. 그림의 셀은 실행 중 잘라 표시하며 원본 PNG를 수정하지 않았다. 화면이 숨겨지거나 앱이 중단되면 새 배경·인사·눈깜박임 동작을 멈춘다. 저자극 설정과 운영체제의 동작 줄이기도 따른다.

기존 그림을 참고 이미지로 제공해 **내장 imagegen의 투명 배경 생성 모드**로 제작했다. 이번 그래픽 작업의 Gemini API 요청은 0회다. 전체 프롬프트는 [기본 그림](prompts.json), [바닥](terrain_prompt.json), [활동 그림](activity_prompt.json)에 저장했다. [manifest.json](manifest.json)에 실제 크기·용량·SHA-256·생성 결과 ID를 기록했다.

에이전트가 셀 경계, 발·귀 잘림, 장면 배치와 입력을 확인했다. 새 그림의 보호자 직접 검수와 사용권 확인은 기록하지 않았으며 기존 자산의 승인 날짜를 복사하지 않았다.

## 검증

- 전체 Flutter 자동 테스트 296개 통과. 그림 비교 검사와 먹이주기 중복 입력·표정 전환, 동작 줄이기 검사를 포함한다.
- 마지막 버스 승객 배치 조정 후 관련 그림·놀이 동작 검사 16개를 기준 이미지 갱신 없이 재검사해 통과했다.
- 가로·작은 세로 화면에서 59개 관련 검사 통과 후 기준 이미지 갱신 없이 전체 검사를 통과했다.
- 실로폰 세로 배치의 무한 높이 오류와 장식용 꽃이 구름 터치를 가리던 문제를 수정했다.
- `flutter analyze --no-pub`에서 문제 없음. `flutter build bundle --debug --no-pub` 성공 후 새 이미지 5장의 번들 파일 SHA-256이 원본과 일치함을 확인했다.
- 실제 휴대폰의 프레임 속도·메모리·스피커 출력과 가족 관찰은 이번 작업에서 측정하지 않았다.
