# 모모숲 비공개 가족 관찰 준비표

상태: 2026-09-30 관찰 준비까지 구현. 사용자가 현재 참여 가족·실제 휴대폰을 준비할 수 없어 실제 가족 관찰은 진행하지 않았다. 아래의 모집 수와 통과 기준은 계획이며 결과가 아니다. 앱에는 승인된 월령 놀이 72개(보호자 놀이 30개, 디지털 놀이 42개), 기존 놀이 10개와 장난감 5종이 있다. 이 문서는 동의서를 대신하지 않는다.

## 시작 전 조건

- 창업자가 사용할 놀이의 대본·그림·음원·조작을 끝까지 검수하고 권리 기록을 남긴다. 해당 놀이가 아이 모드에서 승인 상태로 나타나는지 확인한다.
- Android폰, iPhone, 태블릿의 내부 빌드에서 놀이 시작·종료, 소리 크기, 화면 회전, 네트워크 차단을 확인한다. 실기기가 없으면 가족 관찰 일정을 확정하지 않는다.
- 보호자에게 비공개 시제품의 목적, 관찰 항목, 중단 방법을 설명하고 동의를 받는다. 보호자가 아이 옆에 머문다.
- 실명·정확한 생년월일·연락처·사진·영상·아이 음성을 관찰 기록에 넣지 않는다. 연락처가 모집에 필요하면 관찰 기록과 분리해 보관한다.

## 모집과 배치

- 1차로 24~35개월·36~59개월·60~95개월 미취학 아동이 있는 8~12가구를 균형 있게 모집한다. 6~23개월은 보호자용 화면 밖 놀이를 별도 관찰한다. 모든 가구가 모든 놀이를 할 필요는 없다.
- 다섯 주제와 터치·색칠·노래/동작 세 형식이 전체 표본에 포함되도록 배치한다.
- 1차에는 모든 조작 유형(발견·이야기·분류·만들기·리듬·그림·5종 장난감)을 포함한다. 문제가 있던 유형부터 넓혀 놀이별 서로 다른 아이 최소 3명의 관찰 기록을 목표로 한다. 아이가 거부하면 강요하지 않고 그 사실을 기록한다.
- 집 또는 식당과 비슷한 조용한 상황에서 3~7분 활동 1~2개를 시도한다. 노래/동작은 앉은 자세에서만 한다.

## 보호자에게 읽어줄 안내

> 짧은 놀이가 아이에게 재미있고 자연스럽게 끝나는지 보는 비공개 시험입니다. 아직 완성된 앱이 아닙니다. 보호자께서 아이 옆에서 함께 지켜봐 주세요. 아이가 싫어하거나 불편해하면 바로 멈춥니다. 이름, 생년월일, 사진, 영상, 목소리는 기록하지 않습니다. 아이가 어떤 행동을 했는지와 보호자 의견만 익명 코드로 적습니다. 원하지 않으면 언제든 그만둘 수 있습니다.

## 중단과 다음 결정

- 아이가 무서워하거나 몸을 다칠 위험이 보이면 즉시 놀이를 멈추고 해당 버전을 다시 검수한다.
- 같은 놀이에서 아이 둘 이상이 안내 뒤에도 행동을 시작하지 못하거나 보호자가 재미·안전 문제를 지적하면 수정 후 다른 아이에게 재관찰한다.
- 수량 목표를 채우기 위해 미승인 놀이를 보여주지 않는다. 권리·음원·실기기 확인이 지연되면 가족 관찰 일정도 연기한다.
- 8~12가구 결과는 작은 표본의 관찰 자료다. 학습 효과나 시장성을 입증했다고 표현하지 않는다.


## 앱에서 관찰하기

1. 홈의 자물쇠 → 보호자 PIN → **가족 놀이 관찰**에서 준비 순서를 확인한다.
2. **전체 놀이·이어하기**에서 해당 월령 놀이를 미리 확인한다. 조절 아이콘에서 이 놀이만 `함께 시작 / 혼자 탐색 / 비교·규칙 바꾸기`로 조정할 수 있다. 자동 단계 상승은 없다.
3. 아이와 실제로 놀고, 보호자 공간으로 돌아와 관찰 항목을 입력한다. 시작·도움·흥미·종료·화면 밖 놀이 항목은 기본값을 선택하지 않으며 모두 답해야 저장된다.
4. 관찰 화면의 문제별 건수와 다음 점검 제안을 살펴본다. 실제 결과가 없으면 0건이라고 표시한다. 개발자 검증 결과를 가족 관찰로 대신 입력하지 않는다.
5. 필요한 경우 `식별정보 없는 요약 복사`를 사용한다. 닉네임·프로필 ID·정확한 월령·시각·세션 ID는 제외한다. 날짜나 이름이 없는 연령대·기기 유형·놀이 ID·선택 응답만 포함한다. 작은 집단에서는 이 정보만으로도 추정될 수 있으므로 외부 공개용 자료로 취급하지 않는다.
6. 개별 관찰 삭제와 프로필 삭제가 가능하다. 현재 작품·놀이 이력·관찰은 기기 저장이며 서버 동기화는 아직 없다.

## 이번 구현과 검증 범위

- 공통 음성 정책: 배경음악·안내음성·효과음 설정을 분리하고 임시 음소거·백그라운드 일시중단을 적용한다.
- 놀이 이력은 같은 세션의 누적 초를 갱신한다. 15초 간격과 중단/종료 시 체크포인트를 저장한다. OS가 즉시 강제 종료하면 마지막 저장 이후 최대 약 15초 이력과 마지막 입력은 유실될 수 있다.
- 그림·악보·조립·월령별 진행은 드래프트로 복원한다. 5종 장난감은 앱 전환 시 화면 상태를 유지하지만 앱 프로세스가 종료되면 해당 판을 처음부터 시작한다.
- Flame은 7개 조립 놀이의 유한 시험 장면에 적용한다. 가상 재료 규칙이며 실제 물리 법칙이나 학습 효과를 검증한 모델이 아니다. 시험 중 앱을 나가면 명시적으로 이어하기 전까지 진행하지 않는다.
- 프로그램 테스트·시뮬레이터 확인은 실제 아동/보호자 관찰과 구분한다. 소리 체감, 터치 감각, 실제 기기 성능, 아이의 흥미와 종료 반응은 관찰 때 확인한다.
