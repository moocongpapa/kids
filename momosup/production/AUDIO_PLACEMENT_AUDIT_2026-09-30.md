# 소리 배치 점검 · 2026-09-30

## 결론과 검증 범위

안내 음성과 효과음의 기본 연결은 있지만, 모든 놀이에 충분한 말소리가 있는 상태는 아닙니다. 특히 장난감 5종의 전용 안내와 월령 놀이의 종료·화면 밖 안내 음성이 부족합니다.

코드의 재생 경로, 대사와 조작의 대응, 파일 전수 디코딩·신호 수치를 점검했습니다. 실제 휴대폰 스피커 청취나 아이의 반응 관찰을 대신하지 않습니다. '귀여움', 발음의 자연스러움, 실제 체감 음량은 이번 자동 검사로 확정하지 않았습니다. 음성은 기존 승인된 Gemini TTS이며 실제 성우 녹음은 아닙니다.

## 배치 현황

| 영역 | 현재 배치 | 판단 |
| --- | --- | --- |
| 기존 놀이 10개 | 입장 → 시작 안내 → 선택/반응 또는 노래 → 종료 → 화면 밖 활동 | 흐름은 연결됨. 선택 이름 2~4초 + 반응 6~10초가 이어져 빠른 조작에는 길 수 있음 |
| 월령별 디지털 놀이 42개 | 입장 첫 안내, 다음 장면마다 음성, 다시 듣기 | 짧은 장면 안내는 있음. 조작 성공에 대한 말소리와 종료/화면 밖 안내는 전용 음원이 없음 |
| 장난감 5종 | 냠냠·착·팝·바람·건반·완료 효과음 | 전용 시작/도움/휴식 말소리 없음. 그림을 보고 조작해야 하는 비중이 큼 |
| 그림 놀이 | 입장/단계 안내 + 이번 수정의 붓/도장 첫 접촉 효과음 | 선을 그리는 내내 소리를 반복하지 않고 첫 접촉에만 반응 |
| 조립 실험 | 조각 놓기, 시험 결과 | 성공은 착, 고칠 곳이 있으면 부드러운 바람으로 구분 |
| 6~23개월 보호자 안내 30개 | 보호자가 선택한 안내, 일부 인사 노래 | 보호자 화면에서 선택 재생. 아기에게 조작·정답 소리를 반복하지 않음 |

## 파일 전수 검사

총 239개: 한국어 안내 220개, 노래 4개, 효과음 14개, 배경음악 1개.

- 239개 모두 디코딩 성공. 승인 매니페스트 음성·노래 224개의 SHA-256 불일치 0개.
- 16비트 PCM 기준 클리핑 검출 파일 0개.
- -45 dBFS를 넘는 샘플 기준으로 앞 무음 0.5초 초과 0개, 뒤 무음 1초 초과 0개.
- 기존 음성/노래 66개 RMS 중앙값 약 -15.62 dBFS, 월령 안내 156개 약 -20.38 dBFS. 음량 차이가 있어 기존 팩의 재생 게인을 0.65로 낮춤. 개별 음원의 체감 음량이 모두 같다는 뜻은 아님.
- 효과음 길이 0.08~0.81초. 팝·바람·튕김은 다른 효과음보다 RMS가 커 게인을 0.28로, 완료음은 0.32로, 건반/착/냠냠은 0.48로 설정.
- dBFS/RMS는 파일 신호 수치이며 휴대폰 스피커의 음압이나 청력 안전 측정값이 아님.

## 반영한 개선

1. 음성 로딩을 순서대로 처리하고 새 선택 시 이전 요청을 취소. 로딩 중 음소거·앱 이동을 해도 이전 음성이 뒤늦게 시작되지 않음.
2. 같은 안내를 연속해서 누르면 재생 중인 문장을 처음부터 반복하지 않음. 다 들은 뒤 다시 듣기는 가능.
3. 안내 중 효과음은 평소의 38%로, 배경음악은 0.08로 낮춤. 놀이 화면에서는 기존처럼 BGM을 멈춤. 차분한 설정은 효과음을 추가로 낮춤.
4. 동일 효과음의 100ms 이내 연타를 합치고 동시 효과음을 최대 3개로 제한. 앱 이동·놀이 종료에서 남은 효과음을 정리.
5. 그림 첫 접촉 및 기존 터치 선택에 짧은 팝 추가. 까꿍의 주기적인 대기 바람 소리와 한 번 발견할 때 중복되던 착/바람을 정리.
6. 악보 듣기를 누르면 진행 중인 말소리를 멈추고 아이가 선택한 악보를 재생. 초기 안내 도중 앱을 나가도 이어하기에서 안내를 다시 들을 수 있음.
7. 단순 휴식/종료 버튼에는 성공 팡파르 대신 짧은 전환음 사용.

공통 종료에는 “이제 손을 쉬고, 가족과 인사하자.” 같은 짧은 휴식 안내를 후보로 둡니다. 월령별 놀이에는 각 콘텐츠의 화면 밖 활동에 맞는 별도 종료 대사가 필요합니다. 조립 실패 이유·수정 방법 역시 현재는 그림 중심이므로 짧은 안내 후보를 별도 검수해야 합니다.

대사·음원을 새로 제작하면 실제 조작과의 일치, 발음, 말의 길이, 사용권을 확인한 뒤 반영합니다. 다른 놀이의 승인 음성을 문맥이 맞지 않는 장난감에 옮겨 붙이지 않았습니다.
