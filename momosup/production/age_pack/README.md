# 모모숲 월령별 콘텐츠 제작팩

2026-09-29 · 제작자 검수·사용권 확인 완료 / 비공개 시제품

## 제작 범위

- 6~95개월의 12개 구간, 구간마다 6개씩 총 72개 놀이.
- 6~23개월: 실제 보호자와 하는 놀이 30개. 준비물, 세 가지 진행 방법, 3단계 안내, 안전 안내, 화면 밖 마무리 포함.
- 24개월~만 7세 미취학: 디지털 놀이 시제품 42개. 꽃·까꿍 발견, 선택 이야기, 분류, 집·버스·다리·정원 배치, 소리 악보, 자유 그리기의 6개 공통 조작 형식을 사용.
- 진행 대본 216장면, 함께 해요 / 해볼래요 / 바꿔볼래요 변형 216개.
- 한국어 안내 음성 156개: 보호자 안내 30개 + 디지털 장면 안내 126개.
- 보호자가 익혀 직접 불러줄 창작 인사 노래 2곡. 영아에게 자동 재생하지 않음.
- 영상 파일 대신 Flutter의 사물 변화·등장·배치 애니메이션을 사용. 조용한 설정과 운영체제 동작 줄이기를 지원.

42개 시제품이 모두 별개의 전용 게임 엔진을 가진 것은 아니다. 특히 축제·관점 이야기·다리·공간 설계는 위 공통 조작 형식에 작성한 시나리오를 연결한 첫 구현이다. 다리와 바람 연출은 실제 물리 법칙이나 학습 효과를 검증하는 기능이 아니다. 가족 사용 관찰을 거쳐 장면별 표현과 분기 반응을 더 다듬을 대상이다.

## 앱에서 확인하기

1. 홈의 자물쇠 → 보호자 PIN → **월령별 놀이 72개**.
2. 월령을 골라 6개 놀이를 확인하고, 한 놀이의 세 가지 진행 방법을 비교.
3. 각 장면의 음성 / 해당 놀이의 인사 노래를 따로 듣기.
4. 6~23개월: **안내 끝 · 휴대폰 내려놓기**를 누르면 음성과 음악이 멈춤. 완료 버튼이나 아동 이용 기록 없이 실제 놀이.
5. 24개월 이상: **이 단계로 직접 미리 놀기**로 입력과 마무리를 확인. 미리보기는 아이 이용시간을 기록하지 않음.
6. 이번에 승인된 콘텐츠는 별도 재검수 없이 월령에 맞게 홈과 놀이숲에 나타남. 디지털 놀이 상세에서 **이 기기에서 숨기기 / 다시 보이기**로 표시를 조절.

이번 승인은 제작자의 명시적 검수·사용권 확인에 따라 번들에 기록했다. 대본과 미디어 메타데이터의 승인 해시, 실제 오디오 파일의 해시를 함께 확인하며 변경 시 기존 승인이 적용되지 않는다. 기기별 숨김 설정과 향후 미승인 초안의 로컬 검수는 보안 저장소에 별도로 보존한다. 기존 10개 콘텐츠·66개 음성·10개 그림의 승인은 유지하며 이번 새 콘텐츠는 [별도 확인 기록](REVIEW_STATUS_2026-09-29.md)에 근거한다.

프로필은 6~95개월을 직접 지정한다. 정확한 생년월일을 받거나 월령을 자동 증가시키지 않으므로 자라면 보호자가 수정한다. 만 7세에는 미취학 여부를 별도로 선택한다. 설문을 합산해 발달 점수나 다른 연령으로 변환하지 않는다. 같은 연령의 놀이에서 도움 정도를 직접 고른다.

즐겨찾기는 적합한 다음 월령에서도 유지되며, 영아/디지털 경계 및 취학 경계를 넘어서 콘텐츠를 열지 않는다. 추천은 관심·준비물 응답과 익숙한 놀이, 새 놀이, 함께하는 놀이를 참고한다.

## 생성과 검증

```sh
# 앱 디렉터리(momosup)에서 실행. 로컬 .env 또는 환경변수의 키를 사용.
node tool/generate_age_audio.mjs                              # 생성 예정 목록 확인
node tool/generate_age_audio.mjs --adult-preview --all       # 없는 음성만 이어 제작
node tool/generate_age_music.mjs --adult-preview             # 노래 제작
node tool/compress_age_audio.mjs --ffmpeg=/path/to/ffmpeg    # 생성 종료 후 AAC 변환
node tool/audit_age_pack.mjs                                # 대본·파일·해시·음량 메타데이터
node --test tool/age_pack.test.mjs
flutter test
flutter analyze
```

- API는 성인 제작 도구에서만 호출한다. 앱에 키, 생성 API, 카메라·마이크 수집을 추가하지 않았다.
- 대본만 API로 전송한다. 아동 이름·가족 기록은 보내지 않는다.
- 모델별 일/분 한도를 만나면 지원되는 TTS 모델로 전환하거나 서버 재시도 시간을 따른다. 실제 모델을 각 파일에 기록한다.
- 생성 중 중복 프로세스가 남았던 파일은 해시를 다시 검사해 복구했다. 정확한 모델 기록이 사라진 파일은 `unrecorded-recovered`로 표시하며 모델을 추정해 기입하지 않는다.
- 생성 도구의 잠금은 동시 실행을 막는다. 비정상 종료 후 lock 파일이 남으면 기록된 PID가 실제 실행 중인지 확인한 다음에만 제거한다.
- 원본은 무시되는 `production/audio_wav/age_pack/`에 보존. 앱용 음성은 AAC 64 kbps / mono / 24 kHz로 변환하고 다시 디코딩해 길이·최대 진폭·클리핑을 검사한다. 목표 음량은 -20 LUFS, 최대 true peak -3 dB이다. 이 숫자는 실제 청취나 기기 음량 검수를 대신하지 않는다.
- 실제 생성 수·길이·모델·SHA-256은 `assets/content/age_audio_manifest.json`, 노래는 `age_music_manifest.json`이 기준이다.
