# 월령별 콘텐츠 검수·사용권 확인 기록

## 확인 근거와 범위

2026-09-29, 제작자는 이 Codex 작업에서 새 월령별 콘텐츠팩 제작 결과를 안내받은 뒤 **“검수랑 사용권 확인 완료했어! 반영해줘”**라고 답했다. 아래 승인은 이 제작자 확인에 근거한다.

- 월령별 놀이 72개: 보호자용 실제 놀이 30개, 디지털 놀이 시제품 42개. 세 단계 대본과 변형 포함.
- Gemini로 생성한 한국어 안내 음성 156개 및 보호자 시범용 인사 노래 2곡.
- 승인 기록 시각: 2026-09-29 13:23:48 KST (04:23:48 UTC). 실제 검수 수행 시각을 추정한 값이 아니라 확인을 기록한 시각이다.

이 기록은 제작자가 직접 검수하고 이용권을 확인했다는 진술을 보존한다. Codex가 직접 청취·계약 심사를 했거나 공급자의 별도 서면 허가를 받았다는 의미가 아니다. 원본 계약 자료와 비밀 정보는 저장소에 넣지 않는다. 기존 놀이 10개·음성 66개·그림 10개의 이전 확인은 [기존 기록](../REVIEW_STATUS_2026-09-29.md)에 보존되어 있다.

## 앱 반영

- `age_journeys.json`, `age_audio_manifest.json`, `age_music_manifest.json`의 개별 항목을 `APPROVED`로 변경하고 확인 시각, 사용권 확인 근거, 승인 당시 내용의 SHA-256을 기록했다.
- 대본·미디어 메타데이터의 승인 해시와 실제 음성 파일 해시가 모두 일치해야 번들 승인을 적용한다. 변경된 콘텐츠에는 이번 승인을 자동 적용하지 않는다.
- 앱을 업데이트하면 별도의 기기별 재검수 없이 월령에 맞는 놀이가 홈과 놀이숲에 나타난다. 보호자 영역에서 개별 디지털 놀이를 이 기기에서 숨기거나 다시 보이게 할 수 있다.
- 6~23개월은 PIN을 거치는 보호자 안내와 화면 밖 실제 놀이를 유지한다. 아이용 디지털 게임이나 자동 음악 재생을 열지 않는다.
- 24~95개월은 월령에 맞는 디지털 놀이를 제공하며, 만 7세는 미취학 설정을 적용한다.

앱의 번들 콘텐츠 승인에 관한 기록이다. 공개 스토어 출시나 Render 원격 카탈로그 배포를 뜻하지 않는다. 미디어 모델명이 복구되지 않은 20개 파일은 기존의 `unrecorded-recovered` 기록을 유지한다.

## 확인 명령

앱 디렉터리에서 `node tool/audit_age_pack.mjs --release` 및 `dart run tool/audit_content.dart --release`로 현재 승인 해시·파일·검수 기록을 확인한다. 기술 검사는 제작자의 검수 확인과 별도로 수행한다.
