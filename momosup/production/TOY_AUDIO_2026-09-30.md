# 장난감 음성·음악 제작 및 적용 · 2026-09-30

## 제작 결과

사용자가 이번 대화에서 “장난감에 필요한 안내 음성이나 배경음악 gemini flow api 활용해서 제작하고 적용해줘”라고 요청한 범위에 따라 앱에 연결했습니다.

- Gemini 3.8 Flash TTS / Kore: 한국어 안내 16개, 각 약 2.9~5.7초.
- Lyria 3 Clip API: 보컬 없는 배경 연주 2곡, 약 28.3초와 30.8초.
- Gemini 3.8 Flash 오디오 이해: 최종 인코딩 파일에서 대사를 전사해 원문과 비교하고, 음악의 보컬·급작스러운 잡음 유무를 자동 검사했습니다. 어긋난 음성은 다시 생성했습니다.
- AAC 64 kbps, mono 24 kHz. 새 앱 자산 전체 용량 1,068,122 bytes(약 1.02 MiB).
- 안내 RMS 약 -22 dBFS, 음악 약 -25 dBFS로 처리했습니다. 앞뒤에는 짧은 페이드가 있고 음악은 부드럽게 끝난 뒤 반복합니다. 무음 없는 크로스페이드 루프는 아닙니다.

기존 Flow 웹 제작물을 가져온 것은 아닙니다. 기존에 연결된 Google Gemini API에서 TTS와 Lyria를 직접 사용했습니다. 공식 문서: [Gemini TTS](https://ai.google.dev/gemini-api/docs/speech-generation), [Lyria 음악 생성](https://ai.google.dev/gemini-api/docs/music-generation), [오디오 이해](https://ai.google.dev/gemini-api/docs/audio).

## 앱 배치

| 장난감 | 입장 안내 | 배경음악 |
| --- | --- | --- |
| 냠냠 열매 | 열매를 톡 눌러, 모모에게 나눠 줄까? | 소풍: 부드러운 기타 중심 연주 |
| 도토리 쏙쏙 | 큰 도토리는 큰 바구니에, 작은 건 작은 바구니에. | 숲 공터: 피아노·잔잔한 반짝임 |
| 풀숲 까꿍 | 풀숲을 톡 눌러 볼까? 어떤 친구가 있을까? | 소풍 연주 |
| 숲속 딩동 | 나무 건반을 톡. 네 소리를 들려줘. | 없음: 아이의 건반 소리에 집중 |
| 그림자 착착 | 친구 조각을 골라, 같은 그림자에 놓아 줘. | 숲 공터 연주 |

- 입장 안내는 한 번, 첫 라운드 완료 반응도 한 번만 재생합니다. 매 터치마다 말로 칭찬하지 않습니다.
- 쉬기/종료에서는 각 놀이에 맞는 가족 활동 안내가 나옵니다.
- 오른쪽 위 스피커 버튼은 현재 조작 안내를 다시 들려줍니다. 종료 화면에서는 휴식 안내를 다시 듣습니다.
- 실로폰의 ‘따라하기’ 전환에는 별도 안내가 있고, 건반을 누르면 말소리를 멈춰 연주가 묻히지 않게 합니다.
- 안내 중 음악 게인은 0.30 → 0.08로 낮아집니다. 보호자의 음악·음성·효과음 설정과 음소거를 따릅니다.
- 앱 이동, 놀이 종료, 화면 닫기에서 음악과 음성을 정리합니다. 중단 후에는 이어하기로 재개합니다.
- 오프라인 번들을 재생하며 앱 안에서 Gemini를 호출하지 않습니다. 키는 로컬 제작 도구에서만 사용합니다.

## 기록의 의미

`toy_audio_manifest.json`에 대사/프롬프트, 생성 모델, 원본·변환 파일 해시, 신호 수치, 자동 검사 결과와 적용 요청 근거를 보존했습니다. 대사나 파일이 바뀌면 현재 검증 결과를 상속하지 않습니다.

이번 요청은 제작 및 적용의 근거로 기록했고, 아직 하지 않은 사람의 직접 청취나 새 사용권 확인을 완료했다고 기록하지 않았습니다. 새 자산의 `humanReviewedAt`은 `null`이고 상태는 기존 팩의 `APPROVED`와 구분되는 `APPLIED_ON_OWNER_REQUEST`입니다. 자동 검사는 발음의 자연스러움이나 실기기 체감 음량을 보장하지 않습니다. 기존 팩의 사람 승인 기록은 변경하지 않았습니다.

## 재현

```sh
cd momosup
node tool/generate_toy_audio.mjs                  # 생성 수량만 확인
node tool/generate_toy_audio.mjs --generate       # 로컬 GEMINI_API_KEY 사용, 통과한 파일은 재사용
python3 tool/audit_audio.py --output /tmp/toy-audio-audit.json
flutter test test/toy_audio_test.dart test/audio_placement_test.dart
```

macOS Core Audio의 `afconvert`를 사용합니다. 원본 생성 파일은 Git에서 제외되는 `production/audio_pending/toy_pack/`에, 앱용 파일은 `assets/audio/toy_pack/`에 있습니다. 실제 이용 아동·가족의 정보는 프롬프트에 넣지 않았습니다.
