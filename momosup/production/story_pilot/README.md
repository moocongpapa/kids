## 미디어 제작

- 영상: Gemini API `gemini-omni-1.1-flash`.
- 한국어 음성: `gemini-3.8-flash-tts`, Kore. 생성 후 별도 받아쓰기로 대사 일치를 검사했다.
- 음악: Lyria `lyria-3-clip-preview`. 세 작품의 약 30초 기악 BGM을 만들고 자동 검수했다. 완성 영상에서 별도 반복 재생하는 용도이며 마음 편 전체 미리보기에는 별도 BGM을 연결했고, 나머지 첫 장면 미리보기에는 내레이션만 들어 있다.
- 스타일 이미지 `forest_reference.png`: built-in imagegen으로 기존 모모·두리·누리를 참고해 제작. 프롬프트는 원본 캐릭터를 유지한 따뜻한 수채화 숲, 낮은 나무 그네, 연못, 글자 없는 16:9 구성이다.
- 첫 생성에는 전체 숲 레퍼런스를 사용했다. 현재는 필요한 캐릭터만 분리 참조하고 앞 장면의 마지막 프레임을 함께 사용한다. 무너진 집의 상태·모모의 감정·등장 순서·달빛의 밤 조명을 검사한다. 마음 편 00–11번 전체의 연결을 장면 모아보기로 확인했다.
- 음성 검사는 말의 높낮이를 반주로 오인하지 않도록 보완했다. 10월 1일에는 캐릭터 이름을 구분하고 `어른`을 명확히 발음하도록 TTS 지시를 추가했다. 아직 영상이 없는 달빛 마지막 대사를 `어른과 함께, 물그릇에…`로 자연스럽게 다듬고 전체 재검수했다. 대사는 일치해야 하며, 독립된 감탄사 `앗/아/어`, 응답 `응/음`, 대본의 특정 구절 `연못의 달`이 `연못에 달`로 받아쓰기되는 표준 발음만 동등 표현으로 허용하고 실제 받아쓰기를 기록한다. 조사 전체를 합치지 않으며 이름·차례·행동·대상 변화는 거부하는 비교 검사 5개를 확인했다. 조사 의의 허용 발음은 [국립국어원 표준 발음법 제5항](https://m.korean.go.kr/front/page/pageView.do?mn_id=95&page_id=P000098)을 따른다. 제목은 정확히 일치해야 한다.
- 그네 편의 아직 제작하지 않은 06·07·11·15번 대사는 실제로 재생하지 않는 노래 종료 대신 그네를 멈추고 다음 친구에게 자리를 바꾸는 행동에 맞춰 수정했다.
- `*.preview.json`은 실제 생성한 9장면의 원본·음성·최종 영상 SHA-256과 자동 검수 기록이다. 큰 원본과 거절된 테이크는 Git에서 제외한 `../story_work/`에 보존한다. 키는 기존 로컬 환경에서만 읽는다.
- 미리보기는 1280×720 H.264/AAC로 앱에 번들해 오프라인 재생한다. 원격 저장소/CDN에는 배포하지 않았다.

## 앱 반영

- 홈 이야기 탭 → 숲속 작은 극장. 완성본은 월령에 맞는 편부터 표시하며 상위 연령 편을 어린 아이에게 노출하지 않는다.
- 보호자 공간 → **이야기숲 영상** → 마음 편 전체 미리보기 1편 + 그네·달빛 첫 장면 미리보기 2편.
- 큰 재생·정지·닫기·음소거·가로 전체 화면 버튼, 제목/첫 장면 음성 듣기, 아이 목록의 즐겨찾기.
- 실제 전경 재생 시간만 하루 이용시간에 합산. 정지·로딩·버퍼링은 제외한다. 앱 전환 후 명시적으로 재생해야 이어진다.
- 위치·즐겨찾기는 프로필별 로컬 보안 저장소에 저장하고 프로필 삭제 시 함께 삭제한다.
- 보호자 미리보기는 아이의 시청 시간·완주 기록을 변경하지 않는다. 다음 영상 자동재생은 없다.
- 내레이션과 별도 배경음악은 음성·음악 설정을 각각 따른다. 마음 편 전체 미리보기에는 새 BGM과 제목 음성이 적용됐다. 나머지 미리보기의 BGM은 아직 연결하지 않았다.

## 10월 1일 API 없이 적용한 준비 작업

이번 오프라인 작업의 생성·검수 API 요청은 **0회**다. 제작 상태는 계속 `WAITING_VIDEO_DAILY_QUOTA_RESET`이며, 추가 영상의 완료로 기록하지 않는다.

- 최신 파일·대본·검수 해시를 검사하는 `story_preflight.mjs`를 추가했다. 정상 재사용 **21장면**, 새 영상 **30장면**, 달빛 02번 수정 **1장면**, 준비된 음성 **52개**다. 저장된 22장면 중 달빛 02번은 정상 재사용 대상에서 제외한다. `preflight.json`에 장면별 상태와 다음 명령을 저장했다.
- 대사·시각 지시가 바뀌면 이전 검수를 재사용하지 않는다. 새 검수 캐시는 대본·원본 영상·음성의 해시를 함께 확인한다. 제목·음악도 현재 제목/음악 지시·통과 항목·실제 파일 해시가 모두 맞으면 API 재검수를 건너뛴다.
- 영상 생성은 `--max-video-requests=N`으로 실행당 실제 요청 수를 제한한다(1–20, 기본 20). 재시도도 차감하며 한도에 도달하면 멈춘다. 월간 지출·일일 한도는 즉시 중단한다. 응답이 불명확한 네트워크 실패는 자동 재요청하지 않는다.
- 모든 제작/검수 요청의 시작·결과·모델·용도·숫자 사용량을 Git 제외 `production/story_work/requests.jsonl`에 남긴다. 키·프롬프트·음성/영상·서버 오류 전문은 기록하지 않는다. 기록 저장이 실패하면 새 요청을 중단한다. 응답 성공 뒤 기록 저장만 실패하면 미디어 응답은 보존하고 다음 요청을 막는다. 결과가 불명확한 기록은 다음 실행도 차단하므로 제공자 내역 확인 후 실제 결과를 기록해야 한다. 과거 요청 수·계정 전체의 남은 한도·금액은 이 새 로컬 기록으로 추정하지 않는다.
- 마음 편의 기존 기악 음악을 1.2초 교차 페이드로 이어지는 **24.37초 반복 자산**으로 편집했다. 원본 음악과 영화는 보존했다. 앱에서 시작 1.5초/끝 3초 동안 음악이 서서히 변하고, 내레이션은 그대로 들린다. 마지막 대사 뒤 여백은 약 **2.94초**다. 편집 근거·원본/결과 해시·시간 순서는 `story_cloud.editing.json`에 있다.
- 음성+BGM 로컬 확인용 영상은 `../story_work/story_cloud/story_cloud_review_mix.mp4`다. 전체 디코딩 통과, 최대 피크 **-2.4dBFS**다. 사람이 청취하거나 네이티브 반복 경계를 확인했다는 기록은 없으며, 음악 설정/차분한 설정에 따라 실제 앱 볼륨은 달라질 수 있다.
- 부모 목록은 **완성본 · 보호자 미리보기**와 **제작 중 · 첫 장면**을 구분하고 음성/음악 설정 상태를 보여 준다. 부모 미리보기에서 아이 즐겨찾기를 저장하지 않는다. 목록 오류 뒤 재시도는 새 읽기를 수행한다.
- 완성본 종료 뒤 큼직한 손 버튼으로 부모와 하는 화면 밖 놀이 안내를 연다. 마음 편은 표정을 따라 보고 느낌 말하기, 그네 편은 실제 장난감으로 차례 바꾸기, 달빛 편은 어른이 준비한 얕은 물그릇의 반사를 함께 관찰하기다. 미완성 첫 장면에는 완주 후 놀이 초대를 표시하지 않는다. 다음 영상 자동재생은 없다.
- 공개 검사는 `passed` 표시만 믿지 않고 현재 대본과 실제 검수 항목, 제목/음악/포스터/영화 해시, 전체 관람 범위, 미해결 수정, 편집 음악의 원본과 결과를 확인한다. 아이 공개에는 세 작품 모두 필요하다. 현재 **아이 0편 / 부모 3편**을 유지한다.

로컬 확인·재개 준비:

```sh
export STORY_API_DISABLED=1
node tool/story_preflight.mjs --save
node --test tool/story_offline.test.mjs
# 기존 검수 오디오 재사용만 확인. 누락되면 요청 전에 차단된다.
node tool/generate_story_pilot.mjs --generate --audio-only
# 완성 영화의 기존 음악을 다시 편집할 때만 실행. FFmpeg 필요.

```

실제 영상 재개는 사용자의 재개 요청 이후 API 차단 환경변수를 해제하고, 사전 검사 결과를 먼저 확인한다. 일일 한도의 초기화는 아직 확인하지 않았다.

```sh
unset STORY_API_DISABLED
node tool/story_preflight.mjs --save
node tool/generate_story_pilot.mjs --generate --episode=story_swing --max-video-requests=5
node tool/generate_story_pilot.mjs --generate --episode=story_moon --repair-scenes=story_moon_02 --max-video-requests=5
```

실행당 5회는 계정의 일일 한도가 아니라 작업자가 정하는 추가 요청 상한이다. 재개 후 작품이 완성되면 전체 영상 검수와 화면 확인을 다시 수행한다. 기존 전체 검수에 붙은 영상 해시가 바뀌면 공개 검사를 통과하지 않는다.

검증: 오프라인 제작/요청/공개 검사 **15개**, Flutter 전체 테스트 **153개** 통과, 정적 분석 문제 없음. 새 부모 세로/가로 기준 이미지를 직접 확인했고 기존 아이 화면 기준 이미지도 통과했다. 작은 320×568 화면에서 재생·종료·놀이 안내의 넘침을 검사했다. 사용자 요청대로 시뮬레이터는 실행하지 않았다.

## 10월 1일 재개

월간 지출 한도는 해제됐다. 영상 일일 요청 제한은 별도다. 10월 1일 오전 7시대와 9시대에 실제 요청으로 재확인했다. 9시대에는 두 장면이 성공한 뒤 다시 일일 제한을 받았다. 다음 재개 시점은 마지막 API 안내 기준 10월 2일 약 09:00 KST이며, 실제 응답으로 다시 확인해야 한다. 구독 플랜 이름으로 API 한도 해제를 추정하지 않으며, 일일 제한 응답을 받으면 다른 프로젝트나 모델로 영상 생성을 우회하지 않고 멈춘다. 별도 제목 음성과 음악 작업은 각각의 모델 한도 안에서 진행했다.


첫 명령은 비용 없는 계획 출력이다. `STORY_FFMPEG=/절대/경로/ffmpeg`도 지원한다. 삭제된 임시 도구를 복구해 `/Users/wanseok/Developer/story-tools/imageio_ffmpeg/binaries/ffmpeg-macos-aarch64-v7.1`에 영구 설치했다. `--audio-only`는 영상 요청 없이 제목/음악 제작과 검수를 수행하며 기존 원본을 재사용한다. `--narration-only`는 장면별 WAV를 생성·받아쓰기 검수하고 원본 해시가 일치하는 검수만 재사용한다. 새 음성에는 영상 요청이 없으며 미완성 컷으로 공개하지 않는다.
