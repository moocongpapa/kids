## 재개 순서

1. 현재 Git 상태와 원격 변경을 확인한다. 사용자의 최신 재개 요청 시점에 실제 미완성 그네 07번으로 한도를 다시 확인한다. 새 작업은 `main`에 검증 후 커밋·푸시한다.
2. 아래 명령을 **순차 실행**한다. 정상 장면은 해시가 일치할 때 재사용한다.
3. 마음 편 10번의 이전 영상은 검수에서 잎사귀 집의 나무 틀·구도를 지적받았다. 생성 전에 보존된 거절 테이크와 09번 마지막 화면을 살펴본다. 이야기와 무관한 사소한 구도 차이 때문에 유효한 컷을 반복 생성하지 않되, 핵심 소품 상태가 실제로 어긋나면 고친다.
4. 달빛 02번은 아직 인물이 들어간 이전 컷이다. 현재 지시는 인물 없는 물결·달 반사 클로즈업이며 밤 조명을 유지한다. `--repair-scenes`로 이 컷만 다시 만든다.
5. 전체 영상·제목 음성·Lyria 음악을 완성한다. `review_story_film.mjs`로 전체 순서를 평가하고 `inspect_story_scenes.mjs`의 장면 모아보기에서 모든 컷을 직접 확인한다. 필요하면 특정 장면만 수정한다.
6. `visual_review.json`에 실제 확인한 최종 영상 해시와 수정 결과를 기록한 뒤에만 공개 차단을 해제한다. 사람/가족 검수 기록을 만들어 내지 않는다.
7. `package_story_pilot.mjs --publish`, `audit_story_pilot.mjs`, Flutter 분석/전체 테스트, iOS·Android 네이티브 재생을 확인한다. 완성본 게시 후 오래된 미리보기 자산을 정리하고 문서를 갱신한다.
8. 네이티브 검사 후 실제 `lib/main.dart` 앱을 다시 설치한다. 테스트 하네스를 사용자의 앱으로 남겨 두지 않는다.

```sh
# momosup 디렉터리, 현재 Mac에 있는 도구
export STORY_FFMPEG=/Users/wanseok/Developer/story-tools/imageio_ffmpeg/binaries/ffmpeg-macos-aarch64-v7.1
node tool/generate_story_pilot.mjs --generate --episode=story_swing
node tool/generate_story_pilot.mjs --generate --episode=story_moon --repair-scenes=story_moon_02
```

`--recheck-scenes=ID`는 영상·음성을 유지하고 검사만 다시 실행한다. `--repair-scenes=ID`는 음성을 유지하고 해당 영상·검수 기록을 백업한 뒤 다시 생성한다. 비용이 발생하므로 대상 ID를 정확히 고른다. 중간에 대사를 바꾸면 같은 이름의 기존 WAV도 점검해야 한다.

## 이번에 바꾼 제작·검증 도구

- 앞 장면의 마지막 프레임과 필요한 캐릭터만 참조하여 장소·인물·소품의 연결을 유지한다. 물 표면 컷에는 인물 참조를 넣지 않는다.
