# 10월 6일 이야기숲 영상 제작 재개 기록

## 현재 상태

**그네 편의 새 장면 6개를 제작·자동 검수·인코딩했다.** 최종 장면은 07·08·09·10·12·13번이며, 그네 편은 13/20장면이 준비됐다. 인물 중복·차례 불일치·발이 지면에 닿지 않는 테이크는 통과로 기록하지 않았다. 10번은 두리의 탑승 상태를 유지하도록 모모·누리만 나오는 근접 컷으로 다시 제작했다.

다음 11번 편집 영상의 검수 요청에서 **Gemini HTTP 402**가 발생해 API 요청을 중단했다. 10월 1일의 일일 요청 제한과 구분한다. 정확한 결제 조건·남은 잔액·재개 시각은 확인되지 않았다. 사용자가 프로젝트 결제를 확인한 뒤 재개한다.

완성 영화는 계속 **1/3편**이다. 앱은 기존 **부모 전체 미리보기 1편 + 첫 장면 미리보기 2편 / 아이 공개 0편**이다. 새로운 전체 영화 검수·사람 검수·네이티브 재생 검증을 완료했다고 기록하지 않았다.

## 11번 수정과 원본 보존

발을 땅에 붙이고 그네를 멈추는 장면에서 반복 오류가 있어 [끝 자세 기준 이미지](duri_stop_keyframe.png)를 built-in imagegen으로 1회 제작했다. [제작 기록](duri_stop_keyframe.json)에 프롬프트·참조·해시가 있다. 이 이미지를 Gemini 영상에도 참조했으나 원본만으로는 검수를 통과하지 못했다.

원본 애니메이션 7.2초에서 0.35초 교차 전환으로 기준 이미지에 연결하고 마지막 자세를 2.8초 유지하는 10초 편집본을 만들었다. 편집 전 원본을 별도 보존했으며, `story_swing_11_clip_edit.json`에 입력·기준 이미지·결과 해시와 편집 방법이 있다. 전체 파일 디코딩과 화면 모아보기만 확인했다. **새 자동 검수 요청이 402로 막혔으므로 아직 승인 장면이 아니다.** 거절되면 편집본을 자동으로 덮어쓰지 않는다.

원본·거절 테이크·개별 완성 장면·요청 원장은 Git 제외 `production/story_work/`에 있다. 이 작업본·체크포인트·기준 이미지·검증 기록은 저장소에 남긴다. 키와 서버 오류 전문은 기록하지 않는다.

## 비용 요청 기록

이번 실제 요청: 영상 17회 성공, 검수 18회 중 17회 성공·1회 HTTP 402. 총 시작 35회 / 성공 34회 / 실패 1회 / 결과 불명 0회. 영상 재시도도 포함된 수치이며 **새 통과 장면 수는 6개**다. built-in imagegen 1회는 이 Gemini 요청 수와 별개다. 계정 전체 사용량이나 정확한 금액은 이 기록으로 계산하지 않는다.

402를 명시적으로 분류하고 자동 재시도 없이 중단하도록 보완했다. 사전 검사는 마지막 결제 오류 뒤 실제 성공 기록이 생기기 전까지 결제 확인 필요 상태를 유지한다.

## 재개 순서

먼저 비용 없는 검사를 한다. 현재 종료 코드 1은 결제 응답과 달빛 03 제작 정보가 미해결임을 뜻한다.

```sh
STORY_API_DISABLED=1 node tool/story_preflight.mjs --save
node --test tool/story_offline.test.mjs
```

**사용자가 결제 확인을 완료한 뒤** 그네 편부터 실행한다. 아래 명령은 11번의 저장된 편집 원본을 다시 검수하고, 통과하면 남은 장면을 이어간다. 거절 시 즉시 멈춰 화면을 확인한다. 5회는 이번 실행의 영상 요청 상한이며 제공자의 잔여 한도가 아니다.

```sh
export STORY_FFMPEG=/Users/wanseok/Developer/story-tools/imageio_ffmpeg/binaries/ffmpeg-macos-aarch64-v7.1
STORY_API_DISABLED=0 node tool/generate_story_pilot.mjs --generate --episode=story_swing --max-video-requests=5 --stop-on-scene-rejection
```

이미 고친 그네 10번이나 편집한 11번에 `--repair-scenes`를 다시 붙이지 않는다. 달빛 03은 보존 원본과 현 대본을 확인하고 제작 정보를 해결한 뒤 진행한다. 생성기는 제작 정보가 없는 원본을 발견하면 새 유료 요청 전에 멈춘다. 당시 기록을 복구할 수 없으면 결제 확인 후 `--repair-scenes=story_moon_03`으로 기존 파일을 보관하고 새로 제작한다. 원본을 삭제하거나 임의의 과거 제작 정보를 만들지 않는다. 달빛 02에만 필요한 시점에 `--repair-scenes=story_moon_02`를 한 번 적용하고, 다음 실행에서는 빼야 새 결과를 다시 폐기하지 않는다.

한 편이 끝나면 전체 영화 API 검수 → 모든 장면의 화면 확인 → 정확한 최종 해시의 검수 기록 → 음성/BGM 편집 및 재생 확인 → 해당 편만 `--reviewed-parent-preview=<ID>`로 반영한다. 부모 미리보기 갱신이 다른 완성 영화의 정보·음악·검수 기록을 덮어쓰지 않도록 회귀 검사를 추가했다.

`--previews`로 기존 전체 마음 편을 첫 장면 모음으로 되돌리지 않는다. `--publish`는 지금 실행하지 않는다. 새 완성 영화와 최종 검수 없이 아이 공개 상태를 바꾸지 않는다.
