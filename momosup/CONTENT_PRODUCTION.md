# 모모숲 콘텐츠 제작 원본 (비공개 시제품)

상태: 2026-09-29 기준 **초안 10개, 아이 모드 승인 0개**. 이 문서는 제작 브리프이며 아동 발달 효과나 안전성을 인증하지 않는다. 앱은 `humanApprovedAt`, `rightsVerifiedAt`, 필수 `audioFiles`가 없는 콘텐츠를 아이 모드에서 숨긴다. 실제 승인 시에는 파일·권리·사람 검수 증빙을 먼저 채워야 한다.

## 세계관·캐릭터

모모숲은 집 또는 식당에서도 3~5분 동안 들를 수 있는 조용한 상상 숲이다. 모모(초록 새)는 호기심 많은 안내자, 두리(곰)는 차분한 친구, 누리(구름)는 여러 마음과 날씨를 표현한다. 세 캐릭터는 성별, 특정 능력, ‘착한 아이’ 역할로 고정하지 않는다. 아이를 경쟁시키거나 보상을 약속하지 않는다. 모든 놀이의 마지막 문장은 쉬거나 화면 밖으로 시선을 옮기도록 한다.

그림은 부드러운 종이 질감, 세이지·크림·연한 산호·하늘색을 쓴다. 장면 전환은 느린 페이드나 작은 이동만 사용한다. 반복 탭에 반응하되 번쩍이는 연출, 갑작스러운 소리, 연속 보상은 만들지 않는다. 사용자의 저자극 설정이 켜지면 불필요한 확대·전환을 없앤다.

사용한 이미지 생성 프롬프트의 공통 방향: “Korean preschool interactive 2D storybook, hand-painted cut-paper aesthetic, sage/cream/coral/sky palette, low stimulation, no text/logos/UI, no frightening details.” 숲길은 세 종류의 발자국을, 버스는 멈춘 차량과 빈 좌석 세 개를, 날씨 배경은 폭풍 없이 맑은 기본 숲을 요청했다. 캐릭터 원본은 둥글고 친근한 새·곰·구름의 투명 배경 2D 일러스트로 생성했다. 원본 프롬프트 전문·모델 버전·생성 일시는 배포 전 자산 기록부에 보완한다.

## 놀이별 인터랙션·음향 브리프

각 줄의 대사는 `assets/content/catalog.json`이 배포 원본이다. 여기 적힌 연출은 추가 제작 지침이다. 안내 음성 64개는 Gemini TTS로 사전 생성하도록 도구를 준비했고, 노래 2개와 필요한 짧은 영상 시안은 Google Flow Music 제작 지침을 별도로 준비했다. **현재 실제 생성 파일은 0개이며 모든 파일을 사람이 직접 끝까지 듣고 승인해야 한다.** 노래·동작 놀이는 가사가 소리로 전달되기 전까지 아이 모드에 올리지 않는다. Gemini API의 아동 대상 앱 약관 적용 범위와 Flow Music 파일 재배포 권리를 확인하지 못하면 생성 파일을 공개 앱에 포함하지 않는다. [Flow Music 작업지시서](production/FLOW_MUSIC_PRODUCTION.md).

### 노래 생성용 초안 브리프

`animal_steps_song`: “3~5세 아이가 앉아서 손으로만 따라 할 수 있는, 새·곰·쉬기 세 구절의 새 한국어 노래. 느린 4/4, 한 소절 5~7초, 자연스러운 성인 목소리, 음정 범위 좁게, 반복은 최대 두 번. 기존 동요를 흉내 내지 말고 가사를 정확히 발음. 갑작스러운 소리·박수 강요·점프 지시 없음.”

`body_hello`: “손 인사·어깨 둥실·손 쉬기 세 구절의 독창적인 한국어 노래. 조용한 식당에서도 행동할 수 있는 느린 템포, 부드러운 성인 목소리, 음악보다 가사 전달 우선. 과장된 아동 목소리·유명 가수 모사·기존 노래 유사성 금지.”

AI 음악 서비스가 가사를 바꾸면 그 결과는 버리고 다시 만든다. 무료 요금제에서 생성한 곡을 상업적으로 배포하지 않는다. 보컬과 반주가 분리되지 않는 경우 발음·음량을 사람이 더 엄격히 확인한다. 가사별 WAV 원본과 앱용 AAC/M4A 또는 OGG 파일을 저장하되 iOS·Android 실기기 재생 시험 후 최종 포맷을 정한다.

## 음성 파일 명세와 검수 게이트

권장 파일명: `<activity-id>__intro.m4a`, `__prompt.m4a`, `__reaction-1.m4a` … `__outro.m4a`, `__offscreen.m4a`; 노래는 `__song.m4a`와 구절별 타이밍 표를 따로 둔다. 각 대사의 끝에 아이가 반응할 여유를 둔다. 말 속도를 무작정 낮춰 로봇처럼 만들지 말고, 3~5세 부모·아이 테스트에서 들림과 이해도를 확인한다. 모든 음원은 이어폰·내장 스피커에서 갑작스러운 피크가 없는지 확인한다.

공개까지의 게이트:

1. 대본·그림·가사에 대해 별도 AI 1차 검사를 하고, 프롬프트·모델·생성일·원본을 보관한다.
2. 창업자가 **각 놀이를 끝까지 직접 누르고**, 그림·영상·음성·효과음 전부를 확인한다.
3. 음성·음악·이미지의 해당 요금제 상업 이용 및 앱 파일 재배포 권리를 확인하고 증빙을 보관한다.
4. 아동 발달·안전상 위험과 저작권 유사성이 있으면 수정·재생성 후 처음부터 다시 검수한다.
5. 승인 버전에만 승인 날짜와 파일 경로를 기록한다. 미승인 버전은 아이 모드에서 계속 숨긴다.

현재 시제품은 별도 AI 1차 검사, 사람 최종 승인, 음성/노래 제작·검수, 상업 이용권 증빙이 **모두 미완료**다. 따라서 10개 모두 보호자 미리보기 전용이다.
