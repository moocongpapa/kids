# 모모숲 · Flutter 비공개 콘텐츠 시제품

이 프로젝트는 [PRD](../PRD.md)의 **비공개 검증판**을 위한 출발점이다. 2026-10-28과 월 ₩200,000은 사용자 확인에 따라 조정 가능한 계획 기준이다. 실기기는 아직 없고 Apple·Google Play·카카오 개발자 계정도 없다. 공개 MVP의 정확한 생년월일 서버 보관과 오프라인 안전 목록 24시간 만료 방향은 선택됐지만 이 시제품에는 실제 아동 정보를 서버로 보내는 기능이 없다. 공개 앱이 아니며 아이 혼자 사용하는 서비스로 배포하면 안 된다. 2026-09-29 창업자가 놀이 10개·음성 66개·그림 10개를 직접 검수하고 사용권을 확인했다고 답했으며, 자산 파일·해시·승인 메타데이터 자동 검사는 통과했다. 이 확인의 범위와 공개 출시 전 작업은 [검수 기록](production/REVIEW_STATUS_2026-09-29.md)에 정리했다.

## 구현한 것

### 개발 중 로그인 없는 접속·생년월일 달력 수정 · 2026-10-01

- 첫 화면과 카카오 시작 화면에 **로그인 없이 시작하기**를 추가했다. 아이 정보·생년월일·보호자 PIN을 등록하면 카카오 SDK 로그인 호출 없이 놀이를 이용한다. 접속 정보는 `local_dev`로 구분해 기기에 저장하며 재실행해도 유지한다. 기존 프로필·계정은 삭제하지 않는다.
- Debug/Profile 빌드에서는 기본으로 켜지고 Release에서는 기본으로 꺼진다. `--dart-define=MOMOSUP_DEV_ACCESS=false`로 끌 수 있다. 개발용 Release 배포에서 필요하면 `--dart-define=MOMOSUP_DEV_ACCESS=true`를 명시한다.
- [Flutter 공식 지역화 설정](https://docs.flutter.dev/ui/internationalization)을 앱과 공통 생년월일 달력에 적용했다. 달력은 자체적으로 한국어 Material·Widgets·Cupertino 리소스를 제공하므로 한국어 설정이 없는 기존 앱 화면에서도 열린다. 생일이 달력 범위 밖이면 초기 선택을 범위 안으로 조정하고, 날짜 선택 취소는 기존 값을 유지한다.
- [카카오 로그인 취소 처리](https://developers.kakao.com/docs/ko/kakaologin/flutter)에 따라 취소 시 계정 로그인으로 다시 보내지 않는다. SDK 실패를 가짜 카카오 계정으로 바꾸던 동작과 토큰 일부를 출력하던 로그를 제거했다. 화면을 닫은 뒤 늦게 응답해도 화면 상태를 갱신하지 않는다.
- 390×844 크기에서 한국어 달력·로그인 취소 → 로그인 없는 등록 → 날짜 확인/취소 → PIN → 저장·복원, 홈에서 바로 등록, 범위 밖 날짜와 SDK 실패를 자동 검증한다. 작은 화면의 캐릭터 선택도 줄바꿈해 잘림을 수정했다. Xcode에서는 앱을 정지한 뒤 다시 Run해야 패키지·접속 설정 변경이 적용된다.
- `test/child_birth_date_picker_test.dart`에서는 한국어 설정이 없는 기본 `MaterialApp`에서 등록·프로필 수정 달력을 연다. 이전 코드에서 첨부된 `No MaterialLocalizations found` 오류를 두 화면 모두 재현했고, 공통 달력 수정 후 취소까지 통과했다. 관련 온보딩 검사 총 15개와 정적 분석, `lib/main.dart`를 대상으로 한 iOS 시뮬레이터 Debug 빌드도 통과했다. 이번 달력 수정의 네이티브 화면 조작은 아직 수행하지 않았다.

### 아이 놀이의 가로 화면 · 2026-10-01

- 기존 놀이 10개·월령 놀이 42개·감각 장난감 5종과 모든 이야기 영상은 가로 방향을 요청한다. 아이 홈·놀이 목록·이야기숲도 가로로 연결한다. 영아의 보호자 안내, 초기 등록과 보호자 설정은 세로로 유지하며, 보호자 미리보기의 놀이·영상은 가로로 연다.
- 놀이판과 도구를 나란히 배치했다. 주요 조작은 64~120 논리 픽셀을 유지하고, 작은 화면의 선택지는 줄바꿈한다. 마무리의 홈 버튼과 영상 종료의 함께 놀이·돌아가기 버튼은 상세 안내를 스크롤하지 않아도 누를 수 있다. 영상의 세로 전환 버튼은 제거했다.
- 페이지별 화면 방향을 관리하며 팝업·뒤로가기·앱 복귀에도 현재 화면에 맞는 방향을 복원한다. 태블릿 창 크기가 바뀌어도 장난감의 진행 상태를 유지한다.
- [Flutter의 화면 방향 제한](https://api.flutter.dev/flutter/services/SystemChrome/setPreferredOrientations.html)에 따라 Android 16 이상 큰 화면과 iPad 멀티태스킹에서는 OS가 회전 요청을 무시할 수 있다. 세로 태블릿 창에서는 버튼을 줄이지 않는 16:9 가로 놀이 영역을 제공한다.
- 가로 자동 검사 81개: 568×320에서 모든 57개 놀이의 시작·놀이판·마무리, 페이지 방향 복원과 앱 복귀, 768×1024 태블릿 창과 상태 유지, 실제 글꼴·그림을 사용하는 화면 기준 이미지 21개. 기준 이미지는 `test/goldens/landscape_*.png`에 있다. 네이티브 영상 디코딩과 실제 휴대폰의 회전·스피커 검수는 아직 수행하지 않았다.
- 이번 변경은 기존 미디어를 사용하며 생성 API를 호출하지 않았다. iOS 앱에서 확인하려면 변경된 Flutter 코드를 다시 빌드해야 한다.

### 이야기숲 영상 제작 · 2026-09-30

영상 전용 극장·재생·연령 분기·이어 보기·이용시간 합산을 추가했다. 월간 지출 한도 상향 뒤 총 19장면을 로컬에서 제작·자동 검사했으며, 영상 모델의 일일 제한으로 사용자의 요청에 따라 10월 1일에 재개한다. 현재 앱의 **보호자 공간 → 이야기숲 영상**에는 각 47초짜리 제작 미리보기 3편만 들어 있다. 3~5분 완성본은 아직 없으며 아이에게 공개하지 않았다. 대본 52장면·생성 결과·수정 사항·재개 방법은 [대표작 제작 기록](production/story_pilot/README.md)에 있다.

- 테스트용 6~95개월 다자녀 프로필, 아바타·성별 선택·5문항 놀이 취향 추천, 보호자가 고르는 세 단계

- 생성된 캐릭터 3개·표정 2개·숲 장면 5개(날씨 변형 2개 포함), 큰 터치 선택지, 단순 2D 반응

- 승인·상업 이용권·필수 음성이 없으면 아이 화면에 표시하지 않는 게이트
- 승인된 활동별 사전 생성 음성·노래 WAV 66개 재생

## 숲속 놀이 디자인 개편 · 2026-09-29

- 아이 홈을 카드 목록에서 숲속 놀이 지도로 바꿨다. 열매·바구니·풀숲·악기·퍼즐을 직접 누르고, 아래의 그림 메뉴로 놀이·이야기·그림·노래 영역을 이동한다.
- 검수된 수채화 숲 배경에 햇살·반딧불·살랑이는 잎과 캐릭터 움직임을 더했다. 조작부는 직접 그린 나무 팻말·잎사귀·도토리 형태다.
- 아이 화면의 긴 안내와 선택지 문장을 줄이고 그림·손짓·기존 안내 음성을 사용한다. 전체 설명은 접근성 레이블과 보호자 미리보기에 남긴다.
- 주요 놀이 버튼은 60~120 논리 픽셀, 색칠 도구는 52~64 논리 픽셀로 배치했다. 먹이기·분류·퍼즐에는 드래그 외에 탭 조작도 지원한다.
- 놀이 마무리는 잎사귀 화환과 휴식 안내로 통일했다. 보호자 PIN, 검수 게이트, 일일 시간 제한, 자동 다음 놀이 없음은 계속 적용한다.
- 차분한 움직임 설정 또는 기기의 동작 줄이기를 켜면 반복 배경·캐릭터 움직임을 멈춘다.
- 화면 회귀 검사: 320×568·390×844 휴대폰과 844×390 가로 홈, 작은 휴대폰의 장난감 5종·마무리, 발자국 놀이. 기준 이미지는 `test/goldens/`에 있다.

## 월령별 콘텐츠 승인 반영 · 2026-09-29

- 6~23개월 보호자용 화면 밖 놀이 30개, 24개월~만 7세 미취학 디지털 놀이 시제품 42개를 추가했다. 월령별 6개 놀이와 세 단계 변형을 제공한다.
- 새 안내 음성 156개와 인사 노래 2곡을 제작했고, 제작자의 검수·사용권 확인을 72개 놀이와 158개 미디어에 기록했다.
- 승인 해시와 실제 파일이 일치하는 콘텐츠는 업데이트 후 월령에 맞게 홈에 나타난다. 보호자는 개별 디지털 놀이를 이 기기에서 숨기거나 다시 보이게 할 수 있다.
- 영아는 보호자 안내만 제공하며, 대본·음성 변경 시 기존 승인을 자동 적용하지 않는다.
- 제작 범위와 공통 게임 엔진의 한계는 [월령별 제작팩](production/age_pack/README.md), 이번 확인 근거는 [승인 기록](production/age_pack/REVIEW_STATUS_2026-09-29.md)에 정리했다.

## 놀이 경험 개선 · 2026-09-29

- **톡, 꽃이 폈네**: 분홍·노랑·보라 꽃의 모양이 다르며 먼저 핀 꽃이 정원에 남는다. 함께 해요에서는 한 꽃, 나머지 단계에서는 세 꽃을 만난다.
- **비가 오면 꽃이 웃어요**: 구름 터치 → 비, 꽃 터치 → 개화, 해 터치 → 햇살로 장면과 실제 조작 대상을 연결했다.
- **비 오는 날의 소풍 배달**: 두리·누리·모모가 차례로 등장한다. 잎 우산, 숲집, 구름 자리, 소풍 바구니, 열매, 친구 모임 등 선택에 따라 화면이 변한다. 오답이나 점수는 없다.
- 처음 누를 곳에는 두 번만 보여주는 손짓을 더했다. 차분한 움직임과 시스템 동작 줄이기에서는 정지 안내를 사용한다. 그림 그리기에는 짧은 선 긋기 안내, 분류 실수에는 맞는 바구니 안내를 제공한다.
- 홈 추천은 캐릭터·소품으로 구분하고 빈 나무 팻말을 제거했다. 보호자 공방 목록은 밝은 단색 바탕에서 읽을 수 있다.
- 보호자 공간 앞부분에서 오늘의 놀이·준비물·예상 시간·시작 방법을 보고 곧바로 함께 시작할 수 있다. 영아는 보호자 안내로 이동한다. 디지털 놀이 종료 뒤 화면 밖 놀이 문장을 보호자에게 보여준다.
- 신규 프로필의 기본값은 **월령 추천**이다. 6~29개월은 함께, 30~59개월은 해보기, 60개월 이상은 바꿔보기로 시작한다. 처음 조작·천천히 안내·아주 짧은 놀이를 선택하면 함께 단계, 조작을 조금 해봤다면 최대 해보기 단계로 조정한다. 발달 평가가 아닌 시작 설정이다. 저장된 수동 단계는 유지하며 보호자 공간에서 추천으로 바꿀 수 있다.
- 기존 검수 대본·음성·승인 해시는 바꾸지 않았다. 이 개선은 코드로 그린 장면과 조작·탐색 흐름에 대한 변경이다. 실제 아이의 재미·발달 효과를 입증한 결과는 아니며 다른 놀이의 공통 조작 형식은 남아 있다.

## 나머지 디지털 놀이 전체 개편 · 2026-09-30

- 별도 미니게임 5종 외에 월령별 42개와 기존 10개를 새 숲 장면에 연결했다. 버스 탑승·소풍·날씨·물건 배달·집과 다리 만들기·악보·그림 공방 등 선택 결과가 장면에 나타난다.
- 만들기와 악보는 다음 장면에도 이어지고, 찾은 친구와 이야기 소품도 남는다. 드래그에는 누르기 대안을 제공한다. 그림 공방은 붓 굵기·도장·되돌리기와 작은 화면의 그리기 입력을 개선했다.
- 각 놀이의 적용 내역은 [52개 전체 개편 목록](../GAME_UPGRADE.md)에 있다. 전체 자동 테스트 82개와 정적 분석을 통과했다. 이 결과는 실제 아이와의 사용성 검증을 대신하지 않는다.

## 아직 구현되지 않은 것

카카오 로그인, 법정대리인 확인, 실제 생년월일 기반 자동 갱신, 완성된 3~5분 스토리와 원격 영상 전송, 실기기 조작·재생 검수, 앱과 서버의 연동, 가족 초대·다기기 동기화, 스토어 구독, 원격 콘텐츠 회수, 공식 개인정보·법률·앱스토어 검토. 로컬 PIN은 시제품 접근 장치일 뿐 법정대리인 인증이 아니다. 실명·정확한 생년월일은 시제품에 넣지 않는다.
